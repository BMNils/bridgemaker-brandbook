# Skills in diesem Repo

`bridgemaker-slides` ist unser eigener Skill. Die zwei Handwerks-Skills
sind geprüfte Kopien aus fremden Repos — sie kommen mit `git clone`
automatisch mit, es muss nichts installiert werden.

| Skill | Quelle | Stand | Lizenz |
|---|---|---|---|
| data-storytelling | [wshobson/agents](https://github.com/wshobson/agents) | b6af371 (Juli 2026) | MIT |
| data-visualization | [anthropics/knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins) | a1d09eb (Juli 2026) | Apache 2.0 |

Aufnahmekriterium: Ein Skill arbeitet lokal. Skills, die Inhalte an
fremde Server schicken, kommen nicht ins Repo — Kundendaten verlassen
unsere Maschinen nicht (deshalb flog `chart-visualization` mit seiner
AntV-API am 22.07.2026 wieder raus).

Der jeweilige Lizenztext liegt als `LICENSE` im Skill-Ordner.
Aktualisieren heißt: Ordner durch den neuen Stand aus dem Quell-Repo
ersetzen, Commit-Hash hier nachziehen. Inhalte der Kopien nicht
editieren — Anpassungen an unseren Look regelt der Skill
`bridgemaker-slides` (Brandbook schlägt Skill).
