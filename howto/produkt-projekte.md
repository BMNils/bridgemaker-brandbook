# Produkt-Projekte im Bridgemaker-Look — so startest du

Du baust ein Dashboard, ein Tool, eine App? Dann starte dein
Projekt so, dass es den Marken-Kanon automatisch kennt und
aktuell hält — ein Befehl, einmalig:

```
node templates/new-app.js ~/Projekte/mein-tool --projekt "Mein Tool"
```

(ausgeführt im Brandbook-Ordner; den bekommst du einmalig von
Nils oder aus GitHub)

Das legt deinen Projektordner an — fertig eingerichtet:

- **Der Kanon liegt im Projekt** (Ordner `brand/`) und hält sich
  selbst aktuell: Bei jedem Claude-Start wird er auf den neuesten
  Stand gebracht.
- **Neue Regeln kommen als Vorschlag zu dir.** Ändert sich der
  Kanon, meldet Claude beim nächsten Start, was sich geändert hat
  und welche Stellen deines Projekts das betrifft — eingebaut wird
  erst, wenn du OK sagst. Kein stilles Umbauen, kein
  Hinterherlaufen.
- **Claude kennt die Regeln von allein.** Die Projekt-Anweisungen
  zeigen auf den Kanon; Farben, Schriften und Bausteine kommen aus
  einer Quelle statt aus Kopien, die veralten.

Mehr brauchst du nicht. Arbeite einfach — und wenn Claude beim
Start ein „Kanon-Update" meldet, lies kurz mit und gib dein OK.
